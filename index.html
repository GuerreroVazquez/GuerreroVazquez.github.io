Projects

Featured Project

Machine Learning for Muscle Ageing Prediction

Developed a machine learning model to predict biological age from muscle transcriptomes, identifying key genetic markers associated with ageing. This project involved extensive data curation, feature engineering, and model validation, resulting in a predictive accuracy of R²=0.91. This predictor can display the personalised genes per individual using Shapley Additive exPlanations values.

Featured Project

All-MirKat: A Suite for miRNA Analysis in Muscle Wasting

This project is a BaaS designed to provide researchers, particularly those studying microRNA, a shortcut when searching for target microRNAs. Goes from the differential expression of a condition of interest to the researcher, allowing them to select the pathways, tissues, and cells of interest and provides a short list of microRNAs with relevant interactions and redundancies. This work includes data processing pipelines, network analysis algorithms, and visualisation scripts to uncover novel therapeutic targets.

  • Bioinformatics
  • Data Analysis
